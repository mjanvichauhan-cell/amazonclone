# 🛍️ Amazon Clone Website

A modern Amazon homepage clone built using **HTML5** and **CSS3**. This project replicates the user interface of Amazon's landing page and was created to improve front-end web development skills through hands-on practice.

---

## 📖 About the Project

The goal of this project was to recreate the design of Amazon's homepage as closely as possible. It includes a responsive layout, navigation bar, hero section, shopping categories, and footer while following clean HTML and CSS practices.

---

## ✨ Features

- 🏠 Amazon-inspired homepage design
- 🔍 Functional search bar UI
- 📍 Delivery location section
- 🌐 Language selector
- 👤 Sign In & Account section
- 📦 Returns & Orders section
- 🛒 Shopping cart icon
- 🎯 Hero banner section
- 🛍️ Product category cards
- 🖱️ Hover animations and effects
- 📱 Responsive layout 

---

## 🛠️ Built With

- HTML5
- CSS3
- Font Awesome Icons
